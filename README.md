So this is just a simple hub app for several html/ webports of games I like- quake, hollow knight, etc.
This was developed on a school chromebook so nothing fancy
Unfortunately I do not have the time or effort to properly learn the JavaScript needed for this project so most of the JavaScript is in fact generated by Gemini. However most of the html was made by me.
go to the site and download it as a web app to get full capability
full credit to the developers of the games as well as the original base ports of hollow knight (https://gn-math.dev/?id=468) and Silksong (https://gn-math.dev/?id=771) those ports were made
by gn math and I removed the ads.
quake ports are just cached pages from qwasm and qwasm2.
if you look just shapes and beats is in there but its not addressed in the app- eventually I will add more games like Cuphead, jsab, Undertale maybe, fallout 1/2, etc.
since this is on a chromebook the games are very limited like even a true html port of inscryption couldn't work I would appreciate if someone could get that supported.
games were found on the ultimate catalog of web game ports (https://github.com/Carter54git/Ultimate-Catalog-Of-Web-Game-Ports)

Please keep in mind the quake and quake 2 ports are not fully working so you do need internet to open those but if the app is already open you don't need internet for hollow knight and silksong
if you already downloaded the stuff for them (its automatic when you first open the pages).
